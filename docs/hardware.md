# Reference hardware

| Item | Reference configuration |
| --- | --- |
| Laptop | TECNO MEGABOOK K15S AMD |
| Board/model | K15SDA |
| BIOS used for the Windows fix | 1.10 |
| CPU | AMD Ryzen 5 7430U, 6 cores / 12 threads |
| Integrated GPU | AMD Radeon Vega / Barcelo, PCI `1002:15e7` |

The CPU, GPU, and board information is recorded in the original Hackintosh hardware capture. The Windows backlight fix was tested on the same model and BIOS value. Other configurations are not covered by those results.

## Original captures

See [`hackintosh/hardware`](../hackintosh/hardware) for CPU, PCI, USB, storage, audio, input, and ACPI data. The original [design notes](../hackintosh/docs/specs/2026-07-12-tecno-k15s-hackintosh-design.md) describe the parts captured for that build.

Treat these as a reference for that machine, not a guarantee that every K15SDA ships with identical Wi-Fi, storage, or other components.
